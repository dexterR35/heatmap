# Graphoria workspace branding

This heatmap app is named Heatlens. On 2026-10-18 the user requested a new product name, an app-specific logo, and a lockup with a horizontal divider above "by Graphoria". The same lockup is used in the sidebar, login and footer. The favicon uses the product icon. Inter, the white workspace and the charcoal sidebar remain in use. Account-setup commands and local-environment badges have been removed from the login form.

`heatlens-mark.svg` is a project-native vector heatmap mark, authored for this app. It is independent of the publisher's Graphoria cube. The existing Graphoria assets and Inter fonts below were read from the rendered public homepage on 2026-10-17 and are retained locally. No Graphoria JavaScript or tracking code is included.

Graphoria's `#f23a18` orange is retained as a restrained accent and the first chart-series color. Heatlens uses a dark tile of warm heatmap points as its product icon. The name sits beside the icon; a single horizontal line spans the lockup, with the publisher byline centered below. Tablet navigation collapses to the product icon with an accessible home-link label. Distinct secondary chart series retain their existing analytic colors. Customer names and landing-page registry metadata remain separate from the app's identity.
